# Every Child, Every Table — parent information website

A responsive, offline-friendly HTML/CSS/JavaScript website built in Visual Studio Code, redesigned from the earlier Kindness Arcade. **This version is not a game.** It educates parents, caregivers, schools, and communities about inclusive mealtimes for children with autism, ADHD, sensory feeding differences, and diverse cultural backgrounds.

## How to run
1. Unzip the project.
2. In VS Code, select **File → Open Folder** and choose `every-child-every-table-logo-ready`.
3. Right-click `index.html` and choose **Open with Live Server**, or double-click `index.html` in Finder to open it in a browser.
4. Edit `index.html` for content, `styles.css` for visual design, and `script.js` for interactions.

The site includes no back end, account, forms that submit data, or external analytics. The family plan is stored locally in your current browser, and you can copy or print it. Google Fonts are optional: system fonts are provided as a fallback when offline.

## Sections
- Why autism and ADHD can affect eating differently
- Interactive sensory guide for texture, smell, sound, temperature, and food presentation
- Cultural inclusivity for families, schools, and community celebrations
- Six practical mealtime accommodations
- A printable and copyable family support plan
- Red flags, professional assessment, and ARFID awareness
- Frequently asked questions and reputable sources

## Medical scope
This is an educational website, not a diagnosis or treatment service. Sensory selective eating is not synonymous with ARFID. Seek professional help for persistent nutrition, growth, distress or swallowing concerns. Urgent medical care is appropriate for choking, trouble breathing, severe dehydration, or sudden serious illness.

## New: Cultural food explorer

The cultural-food explorer includes 24 food examples across 8 traditions/regions, with search, region and texture filters, and a one-click way to add a gentle serving idea to the printable family plan. The examples do not assign foods to children by diagnosis or nationality; families should check ingredients, allergies, age safety, dietary requirements and swallowing needs individually. Open `index.html` in VS Code and use Live Server or a browser.

## Add your exact project logo
The site has a responsive, logo-ready header. Save the **actual logo image** as `assets/logo.png` (transparent PNG recommended). On refresh, the header automatically displays the uploaded image. If the file is missing, the original smiling placeholder is shown instead. This is intentional, so the site always works. You can find the `assets` folder beside `index.html` in VS Code.

The logo shared in chat is not bundled until the original image file can be accessed; do not substitute a recreated or unrelated logo.
